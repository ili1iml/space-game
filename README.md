# Space Game 🚀

A little trip back to the games I grew up playing.

Inspired by Galaga, this browser game brings colorful aliens, a starry sky, and a spaceship controlled with your mouse. Built with HTML, CSS, and JavaScript.

## 🎮 Play Live

[Launch Space Game](https://ili1iml.github.io/space-game/)

## How to Play

- Click and hold your spaceship, then drag it to move.
- Your spaceship fires automatically.
- Destroy an enemy to earn **10 points**.
- An enemy escaping through the bottom costs you **10 points**.
- Avoid collisions — you have **3 lives**.
- Click the game screen after **Game Over** to play again.

## Features

- Smooth mouse controls
- Curved enemy attacks
- New waves with increasing speed
- Moving stars and colorful hit effects
- Sound effects for shots and successful hits

Sound starts after your first click inside the game.

## Built With

- HTML
- CSS
- JavaScript
- Canvas API
- Web Audio API

## Run Locally

Download or clone this repository, then open `index.html` in your browser.
